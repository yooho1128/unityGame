# 관객 의뢰 선택과 전투 디자인 — 2026-11-01

반복 전투에서 파티와 상대에 맞는 작은 목표를 고를 수 있도록 관객 주문을 **세 후보 중 선택하는 의뢰**로 확장했다.

## 게임 흐름

1. 전투 시작 시 서로 다른 의뢰 후보 세 개를 정한다. 현재 파티의 약점 공격·상태 기술·서로 다른 기술 보유 여부와 기록 가능 여부를 반영한다.
2. 첫 턴의 첫 행동 전에 화면 왼쪽 위 **의뢰 선택**을 누른다. 목표·달성 보상을 보고 하나를 선택한다. 턴·FP·HP·금화를 소비하지 않는다.
3. 선택은 전투당 한 번이다. 닫기·재열기로 후보가 바뀌지 않는다. 선택 없이 행동하면 처음 정해진 의뢰로 진행한다.
4. 첫 행동을 제출하면 후보 변경을 잠근다. 실제 행동 처리 전 대기 중이거나 이후 턴에서도 바꿀 수 없다.
5. 의뢰를 달성하고 승리·각본 기록으로 마치면 기존 관객 보상을 받는다. 달성 후 패배·도주했을 때의 추가 보상은 없다.

기록 의뢰는 야생전에서만 나온다. 첫 전투 안내 중에는 의뢰를 추가로 표시하지 않는다.
의뢰 보상 금화·달성 FP·누적 기억 조각·연속 흥행 수치는 기존 규칙을 사용한다.
선택 상태는 해당 전투 안에서만 유지하며 게임 저장 스키마 v14를 유지한다.

## 디자인

- 작은 턴 표시와 분리한 **관객 의뢰 티켓**: 목표명, 실제 조건, 기술 종류 진행/제한 턴 게이지, 달성 상태와 보너스.
- **의뢰 카드 보드**: 세 후보를 같은 크기의 카드로 비교하며, 조건과 성공 후 금화 보상을 함께 표시한다. 화면 폭이 좁으면 카드가 세로로 배치된다.
- 전투 명령·정보·메시지 패널에 네이비/아이보리/황동 테마를 적용하고 기본 공격과 결과 확인을 강조했다.
- 캐릭터 정보·HP·파티 슬롯·명령 버튼 배치를 정리해 의뢰 티켓과 전투 정보가 겹치지 않도록 했다.
- 공연 결과 카드를 확장하고 공연 등급 배지와 보상·상세 영역의 정보 계층을 정리했다.
- 기존 생성 프리팹에도 실행 시 적용한다. SafeArea/결과 패널이 없는 구형 구조에는 결과·메시지 카드를 생성하고 올바른 Canvas에 의뢰를 배치한다.
