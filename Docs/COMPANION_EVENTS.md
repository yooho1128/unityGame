# 동행 그림자 지역 이벤트

필드에서는 언제든 파티 UI의 `동행` 버튼으로 따라오는 그림자를 바꿀 수 있다. 특정 그림자와 특정 지역을 탐색하면 일회성 비밀 장면이 발생한다.

- 조건은 게임 UI에 직접 표시하지 않는다. 마을 NPC의 재대화 대사와 환경 묘사로 추측하게 한다.
- 최소 걸음 이후 매 걸음 확률 판정을 하며, `guaranteedSteps`에 도달하면 반드시 발생한다.
- 대화 UI를 열 수 없는 동안에는 완료 처리하지 않고 다음 걸음에 다시 시도한다.
- 완료 여부는 `companion_event_{eventId}_complete` 플래그로 즉시 저장한다.
- 메인 진행과 포털은 잠그지 않으므로 발견하지 못해도 스토리가 막히지 않는다.

초기 핵심 이벤트는 12종이며 설정은 `Assets/Resources/Data/CompanionEventCatalog.json`에서 조정한다. 데이터의 지역·그림자·대화 참조와 걸음/확률 범위는 전체 회귀 검사에 포함된다.

Unity에서 씬을 다시 생성한 뒤 `Tools → Shadow Theater → Generate and Validate Full Game`을 실행하면 60개 필드에 이벤트 컨트롤러가 배치되고 누락 여부를 검사한다.
