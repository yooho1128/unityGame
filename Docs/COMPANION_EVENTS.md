# 동행 그림자 지역 이벤트

필드에서는 언제든 파티 UI의 `동행` 버튼으로 따라오는 그림자를 바꿀 수 있다. 특정 그림자와 특정 지역을 탐색하면 일회성 비밀 장면이 발생한다.

- 조건은 게임 UI에 직접 표시하지 않는다. 마을 NPC의 재대화 대사와 환경 묘사로 추측하게 한다.
- 최소 걸음 이후 매 걸음 확률 판정을 하며, `guaranteedSteps`에 도달하면 반드시 발생한다.
- 대화 UI를 열 수 없는 동안에는 완료 처리하지 않고 다음 걸음에 다시 시도한다.
- 완료 여부는 `companion_event_{eventId}_complete` 플래그로 즉시 저장한다.
- 이전 버전에서 이미 완료한 이벤트는 완료 플래그를 읽어 새 영구 보상을 자동 보충한다.
- 메인 진행은 잠그지 않는다. 동행 전용 숨은 지역 세 곳만 해당 이벤트 완료 플래그를 요구한다.

초기 핵심 이벤트 12종은 결과가 네 유형으로 나뉜다.

- 진명 단서 3종: 빙하 뱃사공 `하론`, 표 없는 승객 `미라`, 먹칠 역무원 `오르도`
- 숨은 지역 3종: 재가 잠든 봉화탑, 거꾸로 흐르는 달길, 바람 없는 메아리굴
- 특별 이동 도구 3종: 귀항의 깃나침반, 혼불 행렬등, 심장 태엽키
- 동행 유대 3종: 얼음 가면의 안전 걸음, 잉크 여우의 조우 확률 감소, 천 조각 고양이의 필드 회복 증가

설정은 `Assets/Resources/Data/CompanionEventCatalog.json`에서 조정한다. 데이터의 지역·그림자·대화·보상 참조와 3/3/3/3 배분은 전체 회귀 검사에 포함된다.

Unity에서 씬을 다시 생성한 뒤 `Tools → Shadow Theater → Generate and Validate Full Game`을 실행하면 63개 필드에 이벤트 컨트롤러가 배치되고 누락 여부를 검사한다.
