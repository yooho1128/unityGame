# 0.1.9 품질 개선 및 QA

## 변경

- 각본집, 파티, 월드맵, 상점, 가방, 퀘스트 기록장, 보스 수첩, 일시정지 메뉴의 패널을 HUD보다 앞에 표시한다. 각본집의 닫기 위치를 메뉴 버튼이 가로채던 현상을 실제 UI raycast로 재현하고 수정했다.
- 각본집을 처음 열면 보유한 그림자를 먼저 선택하고, 다시 열 때 목록 위치를 유지한다.
- 생성 타일 86종 전체를 기존 출시용 환경 아틀라스에 연결한다. 지역별 바닥/벽/장식과 색조를 지정하며 맵 배치와 충돌은 유지한다.
- 필드 HUD의 QuestManager에 적용할 수 없었던 DontDestroyOnLoad 호출을 제거했다. 퀘스트 진행은 기존 SaveData에 보존한다.
- 별도 저장 ID로 실제 Play Mode의 메뉴, 저장 실패 복구, 지역 전환, 전투 복귀를 검사하는 ReleasePlayModeQa 도구를 추가했다.

## 검증 환경과 범위

- Unity 2022.3.62f3. 원본 프로젝트의 기존 변경 및 미추적 생성 파일을 보존하고 별도 검증 복사본에서 임포트/Play Mode/빌드를 수행했다.
- 자동 검사는 GameRegressionValidator, MobilePlayabilityChecks, ReleasePlayModeQa를 사용한다.
- Play Mode의 63개 지역 순회는 명시적으로 지역을 해금한 격리된 QA 저장 데이터로 수행한다. 스토리 전체 수동 클리어를 의미하지 않는다.
- 저장 실패 검사는 의도적으로 QA_EXPECTED_SAVE_FAILURE 예외를 주입한 후 현재 게임 유지와 재시도 성공을 검증한다.
- 2184×1968, 2400×1080, 1920×1080에서 목록/전투 교체/효과/터치 배치를 검사한다. Fold7 실물 검증을 의미하지 않는다.

## 자동 검사 결과

- ReleasePlayModeQa: 종료 코드 0, PASS. 실제 로드 로그의 필드 씬 고유 수 63개. 예상하지 않은 런타임 오류 0건, QuestManager 영속화 경고 0건.
- 메뉴 8종 모두 열기, 최상위 닫기 raycast, 실제 pointer-click, 이동 잠금 해제를 통과했다.
- 신규 저장, 상점 거래/소지 한도, 휴식 비용, 도감 현재 기술/스크롤, 저장 불러오기와 이전 객체 소유권, 쓰러진 개체의 기억 복원, 저장 실패 후 재시도, 전투 자동 해결/결과 확인/필드 복귀를 통과했다.
- 생성 Tile 86/86이 실제 환경 아틀라스 스프라이트와 연결됐으며, 로드된 필드의 사용 타일도 교체 적용을 확인했다. 개별 최종 타일 PNG 89종 교체율과는 별개의 런타임 아틀라스 적용 검사다.
- GameRegressionValidator: 종료 코드 0. 63개 지역, 63개 필드, 180종 그림자, 146개 포털, 3개 고정 인카운터 PASS.
- MobilePlayabilityChecks: 종료 코드 0. 2184×1968, 2400×1080, 1920×1080에서 일반/강제 교체와 파티 6개 스크롤, 근접/마법/회피/연출 중단 복구, 고정 HP·이름 HUD, 피해/치유 표시, 각본집 너비, 동료 크기, 이동 멀티터치 PASS.
- 초반 난이도 자동 대전은 스타터별 640회 중 기사 640승, 마법사 637승, 야수 636승. 직접 수동 플레이 횟수와 구분한다.
- 원본과 검증 복사본의 C#·데이터 카탈로그 204개가 일치한다.

실행 환경의 물리 기기 보고서가 없어 상용 출시 게이트 통과를 선언하지 않는다. 아래에는 최종 APK 직접 확인 결과를 추가한다.


## APK 직접 확인

Android 14 x86_64 AVD에서 ARM64 APK를 변환 실행했다. 0.1.8에서 0.1.9 업데이트 설치 및 기존 파티/저장 유지, 이어하기, 각본집 보유 항목 기본 선택과 닫기, 2184×1968와 2400×1080 실행 중 해상도 변경, 백그라운드 복귀, 이동·NPC 대화·첫 퀘스트 보상/다음 목표, 채색 수레길 포털 이동, 수동 저장·타이틀 복귀·같은 필드 이어하기를 직접 확인했다.

v0.1.9 기기 기록: 오류 0, 저장 8회, 불러오기 3회, 씬 로드 5회, 중단/복귀 각 1회. 최종 logcat의 Unity 예외/치명적 오류 0건. 에뮬레이터의 ARM 변환 및 SwiftShader 환경 평균 약 9 FPS여서 성능 기준은 통과하지 않았다. GPU 가속은 해당 PC 환경에서 부팅 실패하여 소프트웨어 렌더링으로 복구했다. Fold7 실물·음원 청취·스토리 전체 수동 클리어·장시간 실기기 성능은 미검증이다. QA 테스트 APK이며 상용 출시 승인으로 간주하지 않는다.
