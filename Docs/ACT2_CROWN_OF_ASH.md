# 제2막 · 왕관의 재

프롤로그의 달빛 비극을 정화한 뒤 멸망한 왕국으로 넘어가는 첫 장편 막이다. `Generate Playable Prologue`
메뉴가 전환 지역과 제2막 5개 필드까지 함께 생성한다.

## 플레이 동선

`지지 않는 달의 무대 → 찢어진 장막길 → 재의 국경 → 불씨 성도`에서 길이 갈라진다.

- 북쪽: `무너진 병영`에서 무릎 꿇지 않는 대장을 정화
- 동쪽: 병영의 기억을 얻은 뒤 `불씨 지하묘`에서 목 없는 호위기사를 정화
- 마지막: `왕관 없는 옥좌`에서 전설 그림자 재의 왕과 전투

불씨 성도·병영·지하묘 사이에는 되돌아오는 연결로가 있어 일직선 통로가 아니라 마을을 거점으로 탐색한다.

## 신규 콘텐츠

- 일반/희귀 그림자: 불씨 사냥개, 깃발 없는 창병, 화로지기, 종탑 기사, 검댕 궁수, 묘실 촛불, 잿빛 사제
- 지역 보스: 무릎 꿇지 않는 대장, 목 없는 호위기사
- 전설 보스: 재의 왕
- 신규 스킬 20개와 전용 불꽃 왕관 필살기
- 메인 퀘스트 5개, 신규 대화 선택 1개, 보스 전후 컷신 3세트
- 재 황무지, 불씨 도시, 청록 혼불 지하묘, 붉은 왕좌의 조명·안개·합성 환경음

재의 기록관 선택지는 기억 보존, 당사자 배려, 강제 망각 성향을 각각 누적해 최종 엔딩 판정에 반영한다.

## 생성되는 씬

| 씬 | 권장 레벨 | 역할 |
|---|---:|---|
| `CurtainPass` | 11–15 | 프롤로그와 왕국 사이 전환 지역 |
| `AshBorder` | 13–18 | 개방형 재 황무지 사냥터 |
| `CinderCity` | 16–21 | NPC·선택지·분기 포털이 있는 거점 |
| `RuinedBarracks` | 19–26 | 병영 던전과 첫 지역 보스 |
| `EmberCatacombs` | 22–29 | 순환 통로와 두 번째 지역 보스 |
| `CrownlessThrone` | 26–32 | 제2막 전설 보스 무대 |

완성 아트와 녹음 음원이 없을 때는 생성 실루엣, 타일, URP 2D 조명, 합성 환경음으로 즉시 플레이할 수 있다.
