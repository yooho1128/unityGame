# 제7막 · 기억의 바다

`act6_complete` 이후 검은 기록원 동쪽 포털에서 시작한다.

`GlassCoast → DrownedGallery → NameIslands → MourningLighthouse → WidowMoonPalace` 순서로 진행한다.
익사한 화가, 등대를 지키는 상주, 진명 셀레네를 정화하며 이름의 군도 선택은 엔딩 성향에 누적된다.

신규 그림자 10종과 스킬 10개가 추가되고, 마지막 대화에서 `act7_complete`가 기록된다.

## 기억을 듣고 다음 길로 가기

- 유리 해안: 파도 악사는 조각을 모으면 망자가 돌아오는 것이 아니라 남은 목소리를 듣는 일이라고 설명한다.
  초반 검열단 앞에서 했던 기억 보존/망각 선택도 다시 언급한다.
- 물에 잠긴 화랑: 화가가 붙잡은 마지막 그림과 아이들의 문틀 흔적을 통해 미완성의 의미를 이야기한다.
- 이름들의 섬: 보존·공유·봉인의 각 후속 대화가 책임과 남겨진 이들을 구체적으로 짚는다.
  문패 거북의 반복 대사에도 해당 결과가 남는다.
- 애도의 등대: 종지기는 이름 선택에 다르게 반응한다. 애도를 끝내는 것이 종을 없애는 것은 아니라는 합의로 이어진다.
- 미망인의 월궁: 셀레네가 자신의 이름을 되찾고 뒤집힌 로비의 안내원으로 다음 동선을 잇는다.

완료 조건과 선택값은 유지한다. 후속 반응은 8막과 최종 보스까지 연결된다.
구현/검증 범위는 [여정 보강](ADVENTURE_COMPLETION.md)을 참고한다.
