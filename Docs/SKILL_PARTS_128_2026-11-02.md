## 스킬에 적용한 방식

스킬 카탈로그의 **199개 ID 모두**에 시전 징표·이동체·타격 핵심·파편·상징의 다섯 슬롯을 지정했다. 기존 스킬별 궤적·타격 구조·박자·마무리는 유지하면서 새 그림과 자연스러운 종횡비를 사용한다. 섬세한 부품이 뭉개져 보이지 않도록 반복 파편 수를 조정하고, 큰 상징은 화면 가장자리 안에 배치한다.

- 잿불 일격: 불꽃 검격과 폭발, 흩어지는 불씨.
- 무너진 왕관: 불기둥 낙하, 화염 폭발, 대형 왕관.
- 핏빛 송곳니: 발톱 이동과 위/아래 송곳니, 거대한 야수 형상.
- 실 끊기: 교차 절단, 봉합선, 튕겨 나가는 실 끝.
- 기억 꿰매기: 치유 리본, 바늘과 봉합 부품이 자기 몸으로 모임.
- 역조종·천개의 실: 조종 십자, 팽팽한 실, 포박 새장, 거대한 꼭두각시 손.
- 기억의 서고: 책장으로 된 보호 아치, 열린 책과 흩어지는 기록.
- 천공 화장: 운석 궤적, 화염 폭발, 거대한 새 형상.
- 최후의 기립박수: 혜성 꼬리, 은하와 관객 형상.
- 삼키는 대극장: 극장 아치, 은하, 날카로운 공허의 입.

새 그림이 있는 궁극기는 기존 공통 도형 프리팹 대신 새 부품으로 도입부와 타격을 구성한다. 회복은 별도 동작을 유지한다. 기존 전투 규칙·대미지·저장 데이터는 수정하지 않았다.
