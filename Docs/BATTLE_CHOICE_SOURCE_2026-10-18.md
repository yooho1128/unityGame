# 전투 행동 선택과 확률 안내 개선

## 변경

- 기술 목록에 현재 상대의 회피율을 반영한 예상 명중률과 명중 시 평균 피해를 표시한다. 피해는 기존 AI 기대 피해 공식을 사용하며 방어, 속성, 치명타 기대값과 현재 능력치 변화를 반영한다. 실제 피해와 행동 시점의 상태는 달라질 수 있다.
- 회복 기술은 최대 HP 비율 대신 현재 회복 가능한 HP를 미리 표시한다. HP가 가득한 경우 선택을 막는다. FP 획득 기술은 획득량도 표시한다.
- 기술과 합동기의 FP 부족, 합동기 사용 완료, 동행 조건 등 사용 불가 이유를 표시한다. 선택 화면과 실제 제출 검증이 같은 조건을 사용한다.
- 긴 기술 정보와 사용 불가 이유를 읽을 수 있도록 선택 행 높이를 본문에 맞춘다. 창 너비가 바뀌면 다시 계산한다.
- 기록 성공률 표시와 실제 판정이 같은 확률을 사용하도록 동행의 포획 보너스를 포함했다. 기존 실제 포획 공식은 유지한다.
- 한 번 제출한 행동이나 강제 교체는 다음 처리가 시작되기 전의 추가 입력으로 덮어쓸 수 없다. 자동 전투 및 처리 중에는 수동 기술/도구 목록을 열지 않는다.
- 자동 전투 전환 시 수동 목록을 닫고, 수동으로 돌아오면 현재 전투 상태에 맞는 입력 화면을 연다. 제출이 거절되면 화면에 이유를 표시한다.
- 기존 `SubmitAction(action)` 및 `CanUseSkill(skill)` 호출 방식은 유지했다. 새 사유 반환 오버로드를 UI에서 사용한다.

## 확인 범위

- 별도 검증 복사본에서 Unity 2022.3.62f3 컴파일 및 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`로 Editor Play Mode 기동 확인.
- PrologueTheater에서 Player/Grid/GameFlow 초기화 성공, 12초 관찰 중 런타임 오류 0, Unity 종료 코드 0.
- 한글/영문 신규 문구의 JSON 구조와 키 중복 여부, 변경 소스 일치 여부 및 기존 수정 파일의 해시를 확인했다.
- 기존 컴파일 경고는 남아 있다. 실제 전투, 기술 목록의 화면 비율별 표시, 자동/수동 전환 조작은 이번 기동 확인에 포함하지 않았다. 수동 플레이 검증은 사용자가 진행한다.
- APK/AAB 생성과 에뮬레이터 설치, 전체 회귀 검사는 실행하지 않는다. 기존 패키지/에디터 버전 수정과 미추적 생성 파일은 보존한다.
