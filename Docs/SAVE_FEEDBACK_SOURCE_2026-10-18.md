# 저장 결과 안내 및 타이틀 복귀 보호

## 변경

- `SaveManager.TrySave(bool captureRuntimeState = true)`가 파일 교체 완료 여부를 반환한다. 기존 `Save()` API와 저장 파일 형식, 임시/백업 복구 규칙은 유지한다.
- 저장 실패는 `OnSaveFailed`로 알린다. 성공/실패 알림 구독자의 예외는 파일 저장 결과와 분리하고 각 구독자를 개별 호출한다. 한 구독자가 실패해도 다른 구독자에게 알림을 전달한다.
- 메뉴의 수동 저장은 실제 성공 시에만 완료 문구를 표시한다. 실패하면 현재 플레이 데이터를 유지하며 다시 저장하도록 안내한다.
- 타이틀 복귀는 타이틀 씬을 열 수 있고 저장이 성공한 경우에 진행한다. 실패하면 페이드나 씬 이동을 시작하지 않고 메뉴에서 재시도하거나 게임으로 돌아갈 수 있게 한다.
- 지역 이동 후 저장 안내도 이동 직전 저장의 성공 여부에 따라 표시한다. 저장 실패가 지역 이동 자체를 중단하지는 않는다.
- HUD는 저장 매니저 초기화 순서에 대비해 Start에서 구독을 재확인하고, 구독했던 매니저에서 정확히 해제한다. 비활성화 시 표시 코루틴과 HUD를 정리한다.
- 실패 안내를 3.5초간 표시한다. 언어 변경 시 실패 안내가 성공 안내로 바뀌지 않으며, 일반 필드 메시지도 저장 완료 문구로 덮어쓰지 않는다.
- 한글/영문 안내 문구를 추가했다.

## 확인 범위

- 별도 검증 복사본에서 Unity 2022.3.62f3 컴파일 및 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`로 Editor Play Mode 기동 확인.
- PrologueTheater에서 Player/Grid/GameFlow 초기화 성공, 12초 관찰 중 런타임 오류 0, Unity 종료 코드 0.
- 신규 문구의 JSON 구조·키 중복, 변경 소스 일치 여부 및 기존 수정 파일의 해시 확인.
- 기존 컴파일 경고는 남아 있다. 디스크 오류 강제 발생, 메뉴 조작, 지역 이동 및 실제 저장 복구의 플레이 검증은 이번 기동 확인에 포함하지 않았다. 수동 플레이 검증은 사용자가 진행한다.
- APK/AAB 생성, 에뮬레이터 설치 및 전체 회귀 검사는 실행하지 않는다. 기존 패키지/에디터 버전 수정과 미추적 생성 파일은 보존한다.
