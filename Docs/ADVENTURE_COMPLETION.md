# 진화 조건 안내·지역 구조·후반 이야기

요청한 순서대로 게임 안의 진화 안내, 필드 동선, 7~8막 이야기를 보완했다.
저장 버전 v14, 성장 조건/능력치/소비 아이템, 엔딩 판정/선택값/보상은 유지한다.

## 각본집에서 진화 길 찾기

보유한 그림자를 선택한 뒤 **진화 안내**를 연다. 기억 복원/구원/원한 탭으로 나뉘며
현재 레벨, 선행 기억 복원, 기억 조건의 충족 여부와 소비 아이템 없음이 표시된다.
해당 단계가 없는 그림자는 단계가 없다고 안내한다. 최종 형태는 경로를 다시 바꿀 수 없다고 표시한다.

- 44개 조건에 실제 퀘스트·NPC·보스·동행 이벤트로 연결되는 50개 경로를 제공한다.
- 초기 6종은 개인 기억 여정과 기존 이야기 이정표의 대체 경로를 모두 표시한다.
- **이전/다음 방법**으로 경로를 바꾸고 **여정 시작·추적** 또는 **여정 추적**을 누른다.
  개인 기억 여정만 기존 API로 시작하며, 메인 이야기는 임의로 시작하지 않는다.
- **장소 지도**는 현재 미완료 목표나 조건의 NPC/보스/지역으로 초점을 옮긴다.
  각본집 입력 잠금을 해제한 뒤 지도의 잠금을 잡는다. 안내만 읽어서는 진행·플래그를 변경하지 않는다.
- 동행 이벤트는 필요한 동행과 실제 최소/확정 탐색 걸음을 표시한다.
- 미발견 숨은 장소나 소문만 들은 곳의 이름·위치는 가린다. 지도를 통한 조건 우회는 없다.

`EvolutionGuidanceService`는 성장 판정과 동일한 `MemoryAwakeningService.RequirementMet`를 읽는다.
형태 정보는 생성된 실제 `MemoryFormData`를 사용해 레벨 조건이 달라져도 안내에 반영한다.
`Tools/export-evolution-guidance.py`는 JSON·씬 생성 코드·기존 플래그 별칭을 추적한다.
웹 도감 복사본이나 별도 저장소 없이 재생성할 수 있으며 출처 없는 조건은 실패로 처리한다.
기존 생성 프리팹에도 런타임에 안내 버튼/패널을 추가한다.

## 지역별 동선

| 구조 | 특징 |
|---|---|
| 마을 | 중앙 광장·교차 길과 건물 구획 |
| 숲 | 굽은 산책로와 나무 무리 |
| 묘실 | 벽감·묘실과 연결 복도 |
| 서고 | 여러 열의 서가와 가로 통로 |
| 해안 | 물가·나무 길·바위 |
| 습지 | 물웅덩이 사이의 나무 발판 |
| 공방 | 작업대 구획과 통로 |
| 무대 | 중앙 무대와 양쪽 날개 |
| 황무지 | 바위 군집과 굽은 빈 공간 |

`RegionLayoutCatalog`에는 63개 지역과 제작 코드에서 추출한 안전 좌표 396곳이 있다.
달빛 초원은 기존 수작업 지형을 그대로 사용하므로 새 정책 적용 대상은 62곳이다.
기존 23×19 외곽·출구 위치·퀘스트 목표·이동 권능 조건을 유지한다.
`RegionLayoutPolicy`는 지역 ID로 결정적인 바닥/장애물 배치를 만들고, 기존 빈 복도를 우선 이용해
분리된 공간을 연결한다. 목적지와 인접 칸은 접근 공간으로 보호하며 외곽은 열지 않는다.

생성기는 조사물 배치 전에 정책을 적용한다. 생성용 타일은 실제 `.asset`으로 저장하고 기존 GUID를 유지한다.
기존 씬은 로드 시 같은 정책을 적용한다. 현장 콜라이더의 칸, 이동 권능 도착점,
현재 저장 위치와 해당 지역의 체크포인트를 추가로 보호한 뒤 타일 충돌 갱신을 요청한다.
NPC·포털·퍼즐의 오브젝트/조건/보상은 교체하지 않는다.
기존 배치에 따라 안전 공간을 더 확보하므로 생성본과 오래된 씬의 작은 지형 차이가 생길 수 있다.

출시 타일 아트를 재사용한다. 이 작업은 전 지역 전용 타일 원화 제작이나 필드 크기 확장이 아니다.
실제 Unity 렌더링과 물리 충돌을 이 환경에서 확인한 것은 아니다.

## 후반 선택의 반응

33개 대화에 95줄을 추가해 전체 기본 카탈로그는 171개 대화/371줄이 된다.
화가·종지기·셀레네·관리자·최초 배우·마지막 관객의 사연과 다음 동선을 보강했다.
이름 보존/공유/봉인 선택은 문패 거북의 반복 대화, 종지기, 다음 막 안내원,
마지막 연출가와 최종 보스의 말에 각각 반영된다. 초기 검열단 선택도 파도 악사가 다시 언급한다.
여섯 엔딩에는 여정의 장면을 되짚는 대사를 추가했다.

기존 대화 ID·선택지·다음 대화 ID·플래그 변경값을 유지했다.
7막 완료와 최종막 해금/완료 플래그는 추가 대사가 끝난 뒤 기존 순서로 기록된다.
기존 저장으로 이미 본 첫 대화가 자동 재생되지는 않는다. 반복 대화의 새 반응은 재방문 때 표시된다.
후반 상점·정착지 추가와 전투/경제 수치 변경은 포함하지 않는다.

```sh
python Tools/check-adventure-content.py
dotnet run --project Tools/AdventureChecks/AdventureChecks.csproj
python Tools/check-quest-navigation.py
dotnet run --project Tools/QuestChecks/QuestChecks.csproj
```

- **31,731개** 실제 C# 정책 검사 통과: 성장 판정/별칭, 구원 선행 조건, 미발견 장소 비공개,
  63개 지형의 외곽·전체 빈 공간 연결·396개 목적지·막힌 칸에 있던 기존 저장 위치 보호.
  Unity 씬/리소스/저장·그림자 객체는 관리 코드 대역을 쓴다. 네이티브 저장/씬/물리/UI 검사는 아니다.
- 기존 퀘스트 정책 **262개**, 실제 54개 퀘스트/69개 목표 검사 통과.
- 두 카탈로그 재생성 동일 결과, 모든 조건 출처/지역/여정/대화 참조 검사 통과.
- 변경 전후 대화의 선택지/플래그 쓰기/엔딩 입력을 비교해 동일함을 확인했다.
- 공개 UnityEngine 2021.3.33/uGUI 2018.3.5.1 참조 DLL과 기존 Light2D 호환 표면,
  구형 uGUI `selectedColor` 제외를 사용한 런타임 C# 소스 컴파일 오류 0.
  Unity 2022.3 에디터 컴파일을 대신하지 않는다. 변경 C#의 구문 검사도 통과했다.
- `AdventureGuidanceRegression`을 Unity 전체 감사에 연결했다(이 환경에서 미실행).

Unity 2022.3.52f3가 없으므로 에셋 생성/임포트, 에디터 컴파일, Play Mode,
실제 저장 이어하기·모바일 UI·물리 충돌·기기 성능은 확인하지 못했다. APK/AAB를 만들지 않았다.
집 PC의 별도 검증 복사본에서 `Completion → Generate Full Game and Audit`,
`SourceOperationBatch.RunForCi`(`-quit` 제외)와 다음 수동 확인이 필요하다.

1. 초반 기사 개인 기억 여정 시작→추적→지도→NPC 대화→복원, 구원/원한 조건과 숨은 장소 비공개
2. 기존 저장 위치/포털 도착 유지, 지하묘·서고·해안·마을의 이동/대화/조사·레버·숨은 통로·이동 권능

4. 작은 화면에서 스크롤/탭/방법 전환·뒤로 가기·지도 전환 후 입력 잠금, 씬 진입 프레임과 메모리
