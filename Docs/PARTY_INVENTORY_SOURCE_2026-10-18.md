# 파티·서고 교체와 도구 사용 보완

## 추가한 동작

- 파티가 6명일 때 서고의 그림자를 선택하고 `교체 선택`을 누르면 교체할 파티원을 고를 수 있다. `교체 확정`으로 두 슬롯을 한 번에 바꾸며 `교체 취소`로 돌아간다.
- 교체 후 파티에 살아 있는 그림자가 최소 한 명 남아야 한다. 이동하는 동행 그림자는 새로 들어온 그림자 또는 살아 있는 파티원으로 연결한다. 인스턴스 ID, 레벨, HP, 경험치 등 개체 데이터는 유지한다.
- 가방은 선택한 회복 도구의 예상 실제 회복량과 초과 회복량을 표시한다. 사용할 수 없는 경우에는 이유를 표시하고 사용 버튼을 막는다. 이동용 핵심 도구는 경로에서 자동 사용된다고 안내한다.
- 미리보기, 실제 회복, 파티의 자동 회복 도구 선택이 동일한 회복량 계산을 사용한다. 도구 사용 성공 시 회복음을 재생한다.
- 가방·파티·서고·상점 목록 갱신 시 현재 스크롤 위치를 유지하고 새 길이에 맞춰 범위를 제한한다. 새로 화면을 열 때는 맨 위에서 시작한다.
- 가방의 도구/대상 선택과 파티 교체 대상을 강조한다. 갱신 후에도 선택 표시를 복구한다.
- 재생성하기 전 기존 목록을 즉시 비활성화해 한 프레임 동안 클릭 가능한 옛 행이 겹치는 문제를 막았다. 같은 동작의 여러 데이터 변경 이벤트는 모아서 처리해 목록을 반복 생성하지 않는다.
- 비활성 템플릿으로 만든 가방 행도 Bind 시 클릭 리스너를 한 번만 연결하도록 정리했다.

저장 데이터 형식, 생성된 씬/프리팹, 그림자 수치 및 회복 배율은 변경하지 않았다.
