# 월드맵 길 안내 및 수첩 갱신 개선

## 변경

- 경로를 발견한 일반 지역은 방문 전에도 월드맵 목록과 상세 화면에 지역 이름을 표시한다. 출현 그림자, 환경 등 방문 기록은 기존 발견 규칙을 따른다.
- 지역 상세에 알려진 연결 지역을 표시한다. 선택한 목적지까지 알려진 지역 연결을 너비 우선 탐색하여 첫 경유지와 지역 이동 횟수를 안내한다. 미발견 숨은 지역, 소문만 들은 지역, 잠긴 지역과 목적지의 미충족 진입 플래그는 경유하지 않는다.
- 경로 안내는 지역 카탈로그의 연결 정보 기준이다. 실제 출구 위치, 도구가 필요한 지역 내부 이동, 일시적으로 막힌 출구는 현장에서 확인해야 한다. 이동 조건이나 퀘스트 해금 규칙은 변경하지 않았다.
- 월드맵의 방문 수는 현재 카탈로그에서 방문했거나 머물고 있는 지역을 센다. 오래된 저장의 알 수 없는 지역 ID가 수를 부풀리지 않는다.
- 수첩과 월드맵의 선택 항목을 표시하고, 열린 상태에서 내용이나 언어가 갱신될 때 선택 및 스크롤 위치를 유지한다. 필터 변경과 다시 열기에서는 맨 위에서 시작한다.
- 수첩은 매번 현재 저장의 퀘스트 진행 객체로 상세 내용을 다시 연결한다. 선택한 기록이 필터에서 사라지면 첫 기록을 선택하고, 빈 목록은 이전 기록을 비운다.
- 이전 목록 행을 즉시 비활성화하고 갱신 이벤트를 프레임당 한 번으로 모은다. 비활성 템플릿에서 생성한 수첩 항목도 클릭 리스너를 한 번만 연결한다.

## 확인 범위

- 별도 검증 복사본에서 Unity 2022.3.62f3으로 컴파일 및 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi` 실행.
- PrologueTheater의 Editor Play Mode를 12초 관찰. Player/Grid/GameFlow 초기화 성공, 런타임 오류 0, Unity 종료 코드 0.
- 기존 컴파일 경고는 남아 있다. 월드맵/수첩 조작, 화면 비율별 표시 및 실제 길 이동은 수동 플레이 검증 범위이며 이번 기동 확인에 포함하지 않는다.
- APK/AAB 생성, 에뮬레이터 설치 및 전체 회귀 검사는 실행하지 않는다. 기존 패키지/에디터 버전 변경과 미추적 생성 파일은 보존한다.
