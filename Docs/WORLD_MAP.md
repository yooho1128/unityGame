# 40개 지역 월드맵 설계

`Assets/Resources/Data/RegionCatalog.json`이 전체 지역의 단일 원본이다. 각 항목에는 씬 이름, 진행 순서,
연결 지역, 권장 레벨, 분위기, 대표 출현 그림자, 보스, 빠른 이동 도착 좌표가 들어 있다.

|---|---:|---|---|

## 진행 규칙

- 처음 방문한 지역은 `visitedRegionIds`에 저장되고, 카탈로그의 인접 지역은 `unlockedRegionIds`에 추가된다.
- `requiredFlag`가 있는 지역은 인접 경로를 발견해도 해당 스토리 조건을 완료해야 입장할 수 있다.
- 미방문 해금 지역은 월드맵에서 정보를 볼 수 있지만 반드시 필드 출구로 직접 진입해야 한다.
- 한 번 방문한 지역만 월드맵 빠른 이동이 가능하다. 씬이 아직 Build Settings에 없으면 제작 중 안내를 표시한다.
- 구버전 세이브는 현재 위치를 방문한 것으로 자동 복구한다. 지역 진행은 세이브 버전 6부터 저장한다.

## 새 지역 씬 제작 순서

1. `RegionCatalog.json` 항목의 `sceneName`과 같은 이름으로 씬을 만든다.
2. 씬에 `CoreSystems`, 필드 UI, `WorldMapCanvas`, `ScreenFader`, `EventSystem`을 배치한다.
3. `FieldGrid.mapId`를 해당 `sceneName`으로 설정한다.
4. 연결된 지역 방향으로 `MapPortal`을 배치하고 도착 좌표를 카탈로그와 맞춘다.
5. 카탈로그의 `featuredShadows` 콘셉트에 맞는 ShadowData를 제작해 심볼 인카운터에 배치한다.
6. 씬을 Build Settings에 등록한다. 방문 후부터 빠른 이동 버튼이 활성화된다.

`connectedRegionIds`는 양방향으로 작성한다. 분기 지역인 불씨 성도, 월아 숲, 태엽 골목, 끝없는 무대 뒤는
두 갈래 이상의 탐색로를 제공하므로 1자 진행이 아니라 우회·탐색·되돌아오기가 가능하다.
