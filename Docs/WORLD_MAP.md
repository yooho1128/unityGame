# 63개 지역 순환형 월드맵

`Assets/Resources/Data/RegionCatalog.json`이 전체 지역의 단일 원본이다. 기존 40개 지역 ID는 세이브와
퀘스트 호환을 위해 유지하고, 갈림길·숨은 지역·숨은 보스 무대 23개를 추가했다. 플레이어에게는 막 번호
대신 극단 생활권과 지역명이 표시된다.

## 일곱 극단 마을

| 순서 | 마을 | 역할 |
|---:|---|---|
| 1 | 웃음막 유랑촌 | 광대 극단과 플레이어의 시작 마을 |
| 2 | 대학로 극단 거리 | 소극장과 배우가 모인 두 번째 마을 |
| 3 | 물결막 수상극 항구 | 배·고무보트·수상 그림자 이동 거점 |
| 4 | 등불막 그림자촌 | 빛과 장막으로 기억을 비추는 마을 |
| 5 | 달가면 산촌 | 전통 가면극과 산신 의식의 마을 |
| 6 | 실타래 인형극 공방촌 | 인형과 태엽 장치를 만드는 마을 |
| 7 | 별노래 오페라 성도 | 공연 열차와 대극장이 있는 마을 |

마을에서는 야생 그림자 심볼이나 랜덤 전투가 생성되지 않는다. 정비, 상점, 파티·각본 관리와 빠른
이동을 담당한다. 빠른 이동은 방문한 일곱 마을과 유리 해안/뒤집힌 로비의 보급 거점을 대상으로 한다.
두 보급 거점은 필드의 야생 조우를 유지하며 보급·유료 휴식·귀환 지점을 제공한다.
[보급 위치와 사용법](OUTPOSTS_AND_COLLECTION_TOOLS.md).

각 마을에는 30금화로 파티 전원을 회복하는 회복 담당과 생활권의 숨은 길을 직접 밝히지 않고 암시하는
소문 담당 NPC가 한 명씩 있다. 소문을 들은 사실은 `heard_rumor_{regionId}`로 저장되어 월드맵 힌트에
사용할 수 있다. 상점은 작은/일반 회복 시약과 정화 연고를 공통으로 팔고 다음 전문 판매품을 추가한다.

| 마을 | 전문 판매품 |
|---|---|
| 웃음막 유랑촌 | 열기 토닉 |
| 대학로 극단 거리 | 짙은 잉크, 열기 토닉 |
| 물결막 수상극 항구 | 휴대용 고무보트, 농축 회복 시약 |
| 등불막 그림자촌 | 농축 회복 시약, 짙은 잉크 |
| 달가면 산촌 | 무대 열기 영약, 농축 회복 시약 |
| 실타래 인형극 공방촌 | 진명의 은빛 잉크, 무대 열기 영약 |
| 별노래 오페라 성도 | 진명의 은빛 잉크, 짙은 잉크, 무대 열기 영약 |

## 탐험 구조

- 주요 길은 다음 생활권으로 이어지지만 모든 지역이 마을과 연결될 필요는 없다.
- `connectedRegionIds`는 양방향으로 선언한다.
- 채색 수레길, 붉은 포스터 골목, 밀물 판자길 등은 기존 본선에 다시 합류하는 순환로다.
- 숨은 지역은 인접 지역 방문만으로 월드맵에 공개되지 않는다. 실제 입구로 들어간 뒤 등록된다.
- 잊힌 천막촌, 옥상 연습장, 거품 동굴, 그림자 우물, 봉인된 탈방, 장난감 창고,
  노래 없는 회랑은 막다른 탐험 가지다.
- 재가 잠든 봉화탑, 거꾸로 흐르는 달길, 바람 없는 메아리굴은 특정 동행 그림자가 환경의 단서를
  발견한 뒤에만 입구가 열린다.
- 각 막다른 가지의 끝에는 숨겨진 보스 무대가 있다.

## 진행 및 생성 규칙

1. 지역 방문 시 자신과 숨은 지역이 아닌 인접 지역을 세이브에 기록한다.
2. 숨은 지역은 현재 지역과 실제로 연결된 포털을 이용할 때 입장할 수 있다.
3. `requiredFlag`가 있으면 연결을 발견했더라도 해당 이야기 조건을 완료해야 한다.
4. 전체 생성기는 카탈로그의 41~63번 지역을 공통 필드 생성 경로로 만들고 Build Settings에 등록한다.
5. 전체 검증은 지역 63개, 극단 마을 7개, ID·씬·순서 중복, 양방향 연결과 전 지역 도달성을 검사한다.
6. 생성된 씬 검증은 카탈로그 연결과 실제 포털 목적지가 정확히 일치하는지, 같은 목적지 포털이 중복되지 않는지,
   출구 칸과 도착 칸이 모두 걸을 수 있는지 확인한다.
7. 포털 전환 중 모바일 백그라운드 저장이 발생해도 이전 씬 좌표가 목표 도착점을 덮어쓰지 않는다. 막힌 도착점은
   대상 지역의 기본 도착점 주변으로 복구하고, 마을 체크포인트도 함께 보정한다.

## 월드맵 정보 공개

- 현재 지역과 실제 방문을 마친 지역만 이름·환경·권장 레벨·출현 그림자·주요 배역을 공개한다.
- 출구 연결만 발견한 미방문 일반 지역은 `아직 걷지 않은 길`로 표시하며 상세 정보는 감춘다.
- 숨은 지역은 기본적으로 목록에도 나타나지 않는다.
- 생활권의 소문을 들었고, 요구 이야기 조건과 인접 경로 발견 조건까지 충족하면 숨은 입구 하나를 `?`로 표시한다.
- `?`에는 NPC가 말한 환경 단서만 다시 보여 주며 지역명·정확한 위치·레벨·그림자·보스는 공개하지 않는다.
- 실제 입구를 통해 방문한 뒤에만 다른 지역과 같은 상세 정보로 전환한다.

`featuredShadows`와 지역 확장 로스터는 현재 지역의 걸음 기반 랜덤 조우 후보만 구성한다. 대표 목록의
앞쪽 그림자일수록 출현 비중이 높고 희귀종은 낮게 조정된다. 스토리 보스·전설은 일반 조우에서 제외되며,
마을과 보스 전용 무대에는 야생 조우가 없다. 던전은 조우가 잦고 숨겨진 지역은 탐색 여유가 더 길다.

게임 내부 시간은 누적 플레이 시간을 기준으로 6분마다 새벽·낮·해질녘·밤이 순환한다. 날씨는 현실 시계나
재접속 난수 대신 지역 ID와 게임 내 날짜로 결정되어 같은 저장 상태에서는 항상 동일하다. 시간대와 날씨는
필드 조명, 지역 진입 카드, 메뉴·월드맵 환경 정보에 표시되며 관련 속성 그림자의 출현 비중을 소폭 바꾼다.
