# 달빛 초원 기록 퀘스트 진행 정체 수정

`prologue_04_echoes`는 기존 기록을 포함한 총 3종을 확인해야 했으나, 퀘스트 시작 당시의 기록 종수를 기준점으로 삼아 이후 새 3종을 추가로 요구했다. 먼저 잡은 그림자는 기준점 안에 들어가 인정되지 않았고, 초반 출현 종이 적으면 진행이 막혔다.

이 퀘스트를 시작 그림자를 포함한 누적 3종 목표로 명시했다. 화면 설명은 ‘서로 다른 그림자 3종 기록하기 (첫 그림자 포함)’으로 바꿨다. 시작 그림자 1종과 야생 그림자 2종으로 완료할 수 있다. 이미 3종을 기록한 저장 파일은 다음 로드에서 진행도를 복구하며, 등불지기와의 대화 조건은 별도로 유지한다.

첫 포획 퀘스트 `prologue_03_record`도 수락 전에 잡은 그림자를 인정한다. 이 목표에서는 시작 그림자를 제외해 최초 선택만으로 완료되지 않도록 했다. 퀘스트를 새로 받는 시점에도 기존 사실을 반영하므로 현재 기록이 2종이면 다음 누적 목표가 즉시 2/3으로 시작한다.

동일 종의 중복 포획이나 빈 ID는 수집 종수를 늘리지 않는다. 이미 완료한 퀘스트의 보상과 다음 퀘스트는 재접속 시 중복 지급·생성하지 않는다. 새 기록을 추가로 요구하는 개인 기억 퀘스트와 전투 승리 누적 목표는 기존 기준점 규칙을 유지한다. 저장 파일 형식은 변경하지 않았다.

`QuestRecordRegressionChecks`는 실제 퀘스트 관리자와 저장 데이터를 사용해 다음을 검사한다.

- 시작 그림자만으로 첫 포획이 완료되지 않음
- 수락 전 포획 및 다음 목표의 시작 진행도 반영
- 구버전 기준점이 남은 막힌 저장 데이터 복구
- 두 야생 종만 있는 목록으로 누적 3종 목표 완료
- 등불지기 대화가 없으면 해당 조건은 미완료로 유지
- 중복 기록 이벤트로 종수가 증가하지 않음
- 재로드 시 보상 중복 지급 없음

검증 메서드: `ShadowTheater.EditorTools.QuestRecordRegressionChecks.BuildForCi`.

기존 로컬 변경과 원본 생성 씬은 보존하고, 별도 검증 프로젝트에서 컴파일·전체 회귀 검사·Android APK 빌드를 수행한다. 수정 앱은 버전 0.1.2 / Android code 3이며 기존 앱 위에 업데이트 설치한다.
