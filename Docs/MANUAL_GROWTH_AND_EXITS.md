# 수동 전투·경험치 대본 구간·북쪽 포털

## 경험치 대본

사용자가 승인한 상한은 20 / 50 / 80이다. `Assets/Resources/Data/TrainingItemLimits.json`이 단일 기준이다.

| 도구 | 사용 가능 현재 레벨 | 도달 가능한 상한 |
|---|---|---|
| 연습용 기억 대본 | Lv.1~19 | Lv.20 |
| 주석 달린 기억 대본 | Lv.20~49 | Lv.50 |
| 완성된 기억 대본 | Lv.50~79 | Lv.80 |

- 상한 이상이거나 해당 도구의 시작 레벨 미만이면 사용 실패이며 수량이 줄지 않는다.
- 상한까지 남은 경험치만 지급한다. 예를 들어 7 XP가 남았다면 한 권으로 7 XP만 받으며 다음 레벨 경험치를 미리 쌓지 않는다.
- 미리보기와 실제 사용은 같은 정책을 통과한다. 일부만 적용되면 미리보기에 상한 적용을 안내한다.
- 기존 생성 아이템 에셋을 사용하는 빌드에도 종 ID 기준 제한을 적용한다. 미등록 경험치 도구는 사용을 거부한다.
- 상점과 가방 설명, 소스 카탈로그, 웹 아이템 안내에 같은 구간을 표시한다.
- Lv.80 이후는 전투 경험치로 성장한다. 전투 경험치와 아이템 가격·기본 지급 경험치는 변경하지 않았다.

## 자동 전투 제거

- 플레이어 AI 행동 선택과 자동 강제 교체 분기, AUTO API·버튼·프로토타입 자동 층 진행을 제거했다.
- 모든 플레이어 턴과 기절 교체는 입력을 기다린다. 적 AI는 유지한다.
- 과거 SaveData의 `autoBattle` 필드는 호환을 위해 읽되 정리 단계에서 false로 만든다. 전투 Context로 전달하지 않는다.
- 기존 생성 프리팹에 남은 AUTO 버튼도 런타임에서 숨긴다. 새 전투 프리팹 생성기는 AUTO 버튼을 만들지 않는다.
- 에디터 전용 ReleasePlayModeQa는 테스트에서 공격/교체 입력을 직접 제출한다. 출시 게임의 자동 전투 경로를 사용하지 않는다.
- 연출 배속은 기존대로 유지한다.

## 북쪽 포털

소스에서 북쪽 포털은 Y=8, 출시 필드 카메라 크기는 5.5인데 생성기의 카메라 중심 상한은 Y=2였다.
이때 북쪽 포털의 정규화 화면 좌표는 `0.5 + (8-2)/(2×5.5) ≈ 1.045`로 화면 위를 벗어난다.

- 새 생성기의 중심 범위를 Y=±4.5로 조정했다.
- 기존 씬의 알려진 Y=±2 설정도 시작 시 ±4.5로 보정한다. 다른 사용자 지정 경계는 유지한다.
- 새 상한에서 포털은 약 81.8% 높이에 표시된다. 포커스/이동 줌 범위에서도 81~83%이다.
- 포털 표시를 지형 위로 올리고 조명의 영향을 덜 받는 재질을 적용한다. 안쪽 방향에 화살표와 목적지를 표시한다.
- 목적지 공개 여부는 기존 `DestinationName` 규칙을 따른다. 표시는 터치/이동 판정을 가로채지 않는다.

## 검증

- .NET SDK 8 정책 검사 26개: 실제 정책 파일과 JSON을 사용, 구간·상한·초과 경험치·잘못된 상태 검사 통과.
- C# 런타임 소스 Roslyn 검사: 오류 0. 공개 UnityEngine 2021.3.33/uGUI 2018.3.5.1 참조 및 검사 폴더의 URP 호환 표면,
  오래된 uGUI의 selectedColor 대입 제외를 사용했다. 실제 Unity 2022.3 컴파일 검사는 아니다.
- Chromium: AUTO UI 없음, 오래된 AUTO 플래그를 넣어도 턴이 대기함, 수동 공격/강제 교체로 두 전투 종료,
  모바일 가로 넘침 없음, JS 오류 없음 확인.
- 기존 회복·공연 경계·아이템·이스터 에그·난이도·월드맵 검사 통과.
- `TrainingItemRegression` 및 구형 AUTO 플래그 정리의 Unity 회귀 검사 추가(이 환경에서 미실행).

```sh
dotnet run --project Tools/GrowthChecks/GrowthChecks.csproj
python Tools/check-manual-growth.py
node Tools/check-manual-battle.cjs
```

브라우저 검사는 공개 프로토타입만 제공하는 로컬 서버(기본 4176)를 사용한다.
Unity 에디터가 없으므로 임포트·컴파일·RunForCi·Play Mode·포털 육안/실기기 확인은 미완료다.
집 PC에서는 검증 복사본에서 콘텐츠 생성/감사와 SourceOperationBatch.RunForCi(`-quit` 제외)를 실행하고
구형 저장·기존 프리팹·북쪽 포털이 있는 필드에서 카메라/표시/이동을 확인해야 한다. APK/AAB는 만들지 않았다.
