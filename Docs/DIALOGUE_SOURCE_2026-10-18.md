# 대화 중단과 선택 처리 안정화

## 변경

- 없는 대화나 내용이 비어 있는 대화는 시작 실패로 반환하고 완료 콜백을 실행하지 않는다. 실제로 읽지 않은 대화가 NPC 대화 완료, 퀘스트·동행 보상 또는 엔딩 해금으로 처리되지 않도록 한다.
- 대화 시작 API에 선택적인 중단 콜백을 추가했다. 보스의 전투 전 대사, 동행 지역 이벤트, 마지막 선택과 엔딩은 실패·중단 시 대기 상태를 풀어 다시 시도할 수 있다. 동행 대화가 조건에 따라 즉시 끝나는 경우에도 재생 중 상태가 남지 않는다.
- 전투 승리가 이미 정산된 보스의 승리 대사가 시작되지 않으면 기존 승리 후처리를 완료하여 다음 지역 진행을 막지 않는다. 보상 완료 플래그와 중단 복구 규칙은 유지한다.
- 대화를 시작한 프레임의 입력을 받지 않고, 다음/선택 처리는 프레임당 한 번만 허용한다. 키보드와 UI 입력이 같은 프레임에 겹쳐 문장이 건너뛰어지는 것을 막는다.
- 선택 즉시 선택지 입력을 닫은 후 플래그·퀘스트·외부 콜백을 처리한다. 콜백이 대화를 취소하거나 새 대화를 시작하면 이전 대화의 후속 처리를 중단한다. 선택 콜백에서 예외가 나면 현재 대화를 정리한 뒤 예외를 전달한다.
- 다음 대화 연결이 깨진 경우에는 선택 효과를 적용하기 전에 중단하며 완료 처리를 실행하지 않는다.
- 저장 객체가 바뀌면 진행 중 대화를 완료 처리 없이 취소한다. 이동 잠금은 잠금을 걸었던 플레이어에게 해제한다.
- 비활성 선택지에서도 버튼 리스너를 한 번만 연결하고, 숨긴 선택지는 콜백과 버튼 입력을 해제한다. 빈 대사 항목은 건너뛴다.

## 확인 범위

- 현재 대화 카탈로그의 선택지 연결에 누락된 대화 ID가 없고, 최대 선택지 수가 기존 UI의 3개 슬롯 이내인지 소스 데이터 확인.
- 별도 검증 복사본에서 Unity 2022.3.62f3 컴파일 및 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`로 Editor Play Mode 기동 확인.
- PrologueTheater에서 Player/Grid/GameFlow 초기화 성공, 12초 관찰 중 런타임 오류 0, Unity 종료 코드 0.
- 기존 컴파일 경고는 남아 있다. 대화 연타, 중단, NPC 보상, 보스·엔딩의 실제 플레이는 이번 기동 확인에 포함하지 않았다. 수동 플레이 검증은 사용자가 진행한다.
- APK/AAB 생성, 에뮬레이터 설치 및 전체 회귀 검사는 실행하지 않는다. 기존 패키지/에디터 버전 수정과 미추적 생성 파일은 보존한다.
