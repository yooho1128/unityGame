# 플레이 중 설정과 조작 안내

일시정지 메뉴의 설정 버튼으로 타이틀과 같은 전체 설정을 연다. 일시정지 메뉴의 이동 잠금을 유지한 상태로
카드만 숨기므로 설정에서 돌아갈 때 플레이어가 움직이거나 메뉴가 함께 닫히지 않는다. 설정 종료 프레임의
뒤로 가기 입력은 부모 메뉴에서 재처리하지 않는다. 저장 전환이나 메뉴 종료 시에는 설정도 함께 닫는다.

설정에서 마지막으로 열었던 탭을 유지하며, 재진입 시 그 탭에 포커스를 둔다. 설정을 닫을 때는 이전에
선택한 버튼이 유효하면 포커스를 복원하고, 그렇지 않으면 이전 메뉴의 첫 조작 가능한 항목을 선택한다.

플레이 탭의 대화 속도 미리보기는 실제 대화와 같은 속도 및 문장부호 지연을 사용한다. 속도를 바꾸거나
다시 보기 버튼을 누르면 샘플이 처음부터 표시된다. 미리보기는 무음이며 게임의 대사·선택지·저장 상태를
변경하지 않는다. 사운드 탭에는 버튼 소리·대화 소리 샘플을 직접 재생하는 버튼과 음소거 상태 안내가 있다.

조작법 탭은 PC에서는 키보드·단축키·게임패드, 모바일에서는 터치 조작을 안내한다. 선택된 슬라이더의
좌우 조절과 목록 스크롤도 설명한다. 실제 대화 시작/선택지 표시 시 패드 포커스를 해당 UI에 지정한다.
조작법 탭의 위로 보기·아래로 보기 버튼은 패드로도 긴 안내를 스크롤할 수 있게 한다.

## 확인 범위

C# 변경·추가 스크립트 7개의 구문 검사와 새 스크립트 GUID 중복 검사를 통과했다.
번역 JSON의 413개 키가 고유하며, 한·영 키 21개를 추가하고 기존 항목을 보존했음을 확인했다.
`git diff --check`를 통과했다. 스토리 대사 데이터와 저장 스키마에는 변경이 없다.
Unity가 설치되지 않아 Unity 컴파일·Play Mode·입력·화면·실제 음향 검증은 별도 환경에서 필요하다.
APK/AAB 등 Player 빌드는 수행하지 않는다.

Unity에서는 별도 검증 복사본에서 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`로 기동을 확인한다.
그 후 설정→Esc/B→일시정지→Esc/B의 단계별 닫힘, 해상도 드롭다운 취소, 설정 중 저장 슬롯 변경,
속도별 미리보기·음소거 샘플, PC/모바일 조작법, 게임패드 대화 진행/선택지 포커스를 확인한다.
