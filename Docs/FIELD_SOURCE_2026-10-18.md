# 필드 흐름과 출구 안내 보완

사용자 요청에 따라 이번 작업은 소스 수정과 Unity 컴파일/Play Mode 기동 확인으로 제한했다. 작업 기준은 루트 AGENTS.md에 기록했다.

## 소스 변경

- PlayerController: 필드 비활성으로 이동 코루틴이 중단되면 예약된 타일에 위치를 맞추고 이동 상태/입력을 해제한다. 파괴 시 싱글턴 참조도 해제한다.
- RandomEncounterController: 희귀 조우 대기 코루틴을 추적하고 비활성 시 취소한다. 전투/지역 이동과 경합해 취소되면 대기 플래그를 정리한다. 이벤트 구독은 실제 구독한 GameFlow 객체를 통해 해제한다.
- EncounterSymbol: 야생 심볼 재등장을 코루틴 대기 대신 타임스탬프로 관리한다. 다른 전투로 필드가 꺼져도 재활성 시 남은 시간을 이어간다. 깜빡임 중 필드가 꺼져 보이지 않는 심볼이 남는 것도 방지한다. 고정 조우의 영구 제거 규칙은 유지한다.
- GameFlow/MapLoader: 전투 복귀 및 지역 도착 후 1.5초 동안 접촉/랜덤 조우를 유예한다. 전투 중 지도 이동, 지도 전환 중 조우 시작의 경합을 막는다. 스크립트 전투의 진행 조건은 변경하지 않는다.
- MapPortal/VirtualActionButton: 출구를 바라보면 행동 버튼에 이동을 표시하고 목적지 이름을 안내한다. 미발견 숨은 지역은 알 수 없는 길로 표시한다. 접촉형 출구도 상호작용 버튼으로 이동할 수 있다.
- 관련 행동/목적지 문구의 한국어·영어 항목을 추가했다.

기존 생성 씬/프리팹/그림자 데이터 및 저장 형식은 수정하지 않았다.
