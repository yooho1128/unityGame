# 지역 이동 시작 실패 및 패배 복귀 보완

## 변경

- 이동 전에는 현재 필드 위치를 캡처하고, `LoadSceneAsync`가 유효한 요청을 반환한 뒤 목적지 좌표·방문 기록·체크포인트를 기록한다. 로드 요청이 거절된 경우 도착하지 않은 지역을 저장하지 않는다.
- 페이드 도중 저장 객체가 바뀌면 기존 요청을 중단한다. 비활성 MapLoader에서는 이동 코루틴을 시작하지 않는다.
- 씬 로드 시작 예외나 null 요청에 대해 화면을 밝히고 환경음을 되돌리며, 해당 이동에서 걸었던 플레이어 잠금과 전환 상태를 해제한다. 재진입 유예와 실패 안내를 제공한다.
- `TravelTo`와 `LoadSavedMap`에 선택적인 실패 콜백을 추가했다. 사전 조건으로 즉시 거절하면 기존처럼 false를 반환하며, 받아들인 이동이 페이드 후 시작되지 못하면 콜백으로 호출자에게 알린다.
- 타이틀의 이어하기와 새 게임 필드 진입이 페이드 후 실패해도 타이틀을 다시 표시한다. 이어하기는 전환 중 중복 실행하지 않는다.
- 이어하기의 저장 위치 복귀는 일반 출구 해금과 구분한다. 복구 대상은 실제 지역 카탈로그와 빌드에 있는 저장 맵, 체크포인트, 시작 마을 순서로 선택한다. 타이틀 등 필드가 아닌 저장 맵은 복구 대상으로 쓰지 않는다. 일반 이동의 해금 조건은 유지한다.
- 패배 후 다른 맵의 체크포인트 이동이 시작되지 못하면 현재 지역의 안전한 도착점 기준으로 복귀한다. 다른 맵의 좌표를 현재 맵 좌표로 해석하지 않고, 정상 복귀한 위치를 새 체크포인트로 기록한다.
- 거점 이동의 비동기 시작 실패 시 MapLoader 잠금뿐 아니라 남은 전투 잠금도 해제한다. 저장이 교체됐으면 이전 전투의 복귀 처리를 새 저장에 적용하지 않는다.

## 확인 범위

- 별도 검증 복사본에서 Unity 2022.3.62f3 컴파일 및 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`로 Editor Play Mode 기동 확인.
- PrologueTheater에서 Player/Grid/GameFlow 초기화 성공, 12초 관찰 중 런타임 오류 0, Unity 종료 코드 0.
- 한글/영문 신규 문구의 JSON·키 중복 여부, 검증 소스 일치 여부 및 기존 수정 파일 해시 확인.
- 기존 컴파일 경고는 남아 있다. 씬 로드 실패 강제 발생, 이어하기, 포털 이동, 패배 후 복귀의 실제 조작은 이번 기동 확인에 포함하지 않았다. 로드가 시작된 뒤 Unity 내부에서 영구 정지하는 상황에 대한 취소·시간 제한 기능은 추가하지 않았다.
- APK/AAB 생성, 에뮬레이터 설치 및 전체 회귀 검사는 실행하지 않는다. 기존 패키지/에디터 버전 수정과 미추적 생성 파일은 보존한다.
