# 그림형 월드맵

전체 63개 지역을 네 장의 풍경 지도로 표현한다. 마을은 건물·천막·극장으로, 이동 구간은 초원·산길·해안·황무지로 구분한다. AI 생성 아트는 `Assets/Resources/Art/WorldMap/Acts12.png`부터 `Acts78.png`까지 포함되어 있다. 텍스트나 위치 표식은 배경에 포함하지 않는다.

| 지도 | 지역 수 | 테마 |
| --- | ---: | --- |
| 1–2막 | 17 | 유랑촌, 달빛 초원, 장막 산길, 재의 왕국 |
| 3–4막 | 21 | 수상극 항구, 서고, 달가면 산촌, 늪과 달빛 숲 |
| 5–6막 | 15 | 인형 공방, 태엽 도시, 검열단의 흑백 건축 |
| 7–8막 | 10 | 기억의 바다, 떠 있는 섬, 우주의 극장 |

## 게임 연결

`WorldMapController`가 기존 프리팹의 목록 영역을 `WorldMapAtlasView`로 전환한다. 기존 프리팹의 직렬화 필드는 유지되므로 이미 생성한 씬에서도 같은 컨트롤러를 사용한다. 지도는 좌우·상하 드래그, 1–3배 확대, 페이지 전환, 현재 위치와 이동 퀘스트 목적지로 이동하는 버튼을 제공한다.

위치는 `Resources/Data/WorldMapAtlas.json`에 지역 ID별 정규화 좌표로 저장한다(좌상단 원점). 탐험 상태가 바뀌어도 위치가 재정렬되지 않는다. 현재 위치는 청록색, 퀘스트 목적지와 선택 경로는 금색이다. 길 안내는 `FindKnownRoute`의 발견·관문 조건을 그대로 사용한다. 페이지를 가로지르는 이동은 상세 패널의 다음 지역 안내와 페이지 버튼으로 확인한다. 점선은 지역 사이의 안내 표시이며 필드 타일 이동 경로가 아니다.

숨은 지역의 핀은 발견 전 표시하지 않으며 소문 상태에서는 이름을 공개하지 않는다. 배경의 일반 건축·지형은 전체가 보인다. 빠른 이동은 기존처럼 방문한 마을만 허용한다. 대화·토벌 퀘스트에는 별도 목적지 매핑이 없어 이번 목적지 표식은 미완료 Reach 목표에 적용한다.

지도 텍스처는 현재 페이지 한 장만 유지하며, 안내 점선은 점별 GameObject 대신 하나의 UI mesh로 그린다. PNG 임포트는 2048 상한, 비읽기, mipmap 비활성, Texture2D 형식이다.

## 검수

저장소 루트에서 `python3 -m http.server 4173` 실행 후 `Prototype/world-map-atlas.html`을 브라우저로 열면 같은 리소스와 좌표를 검수할 수 있다. 이 화면은 모든 지역을 공개하는 아트 검수용이며, 게임 세이브/해금 조건 및 Unity 렌더링을 재현하지 않는다.

`node Tools/validate-world-map.cjs`로 63개 좌표와 이미지·메타데이터·지역 연결·이동 퀘스트 참조를 검사한다.

2026-10-26 클라우드 검사: 위 데이터 검사와 변경 C# 파일의 Tree-sitter 구문 검사 통과. Chromium에서 네 장 이미지 디코딩, 63개 핀, 선택, 확대/축소, 초원 경로와 모바일 폭의 페이지 이동을 확인했다. Unity 에디터가 설치되어 있지 않아 C# 컴파일과 Play Mode는 실행하지 못했다.

Unity 확인 시 별도 검증 복사본에서 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`를 사용한다(`-quit` 없이). 이어서 지도 마스킹·텍스트 가독성·터치 드래그·반복 열기/닫기·언어 전환·미발견/방문/퀘스트 상태별 표식과 빠른 이동을 확인해야 한다. 별도 요청 없이 APK/AAB는 생성하지 않는다.
