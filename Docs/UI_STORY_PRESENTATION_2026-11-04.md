# UI 및 스토리 연출 개선

- 공통 버튼·패널을 텍스처 확대 대신 둥근 벡터 면과 얇은 테두리로 표시한다. 검색·드롭다운·음량 슬라이더도 같은 스타일을 사용한다.
- 설정 화면은 사운드·화면·플레이 탭, 직접 선택하는 해상도 목록, 대화 속도 선택, 켜짐/꺼짐 스위치를 제공한다. 설정은 기존 PlayerPrefs 경로에 즉시 저장된다.
- 일시정지 메뉴는 가로 화면에서 여정 정보와 음량 설정을 나누고, 자주 쓰는 메뉴와 저장 행동을 아래에 정렬한다.
- 조작 키캡, 게임패드 안내, 버튼 포커스, 전투 HP 피해 잔상과 출전 파티원 표식을 추가한다. 상점은 이동과 충돌하지 않는 O 키를 사용한다.
- 대화 중 음악은 원래 음량의 66%까지 부드럽게 낮아진다. 최신 main의 스킬 덕킹·음악 재생 위치·교차 전환을 보존하며 두 연출이 동시에 작동하면 더 낮은 목표 음량을 따른다.
- 대사는 쉼표·문장부호에서 잠깐 호흡하고, 작은 타자음과 책장 넘김 소리를 사용한다. 즉시 완성 입력은 그대로 동작한다. 전체 문장 기준으로 글자 크기를 미리 정해 타자 중 글자 크기가 변하지 않는다.
- 보스 후 대화 8곳에 cinematic 메타데이터와 짧은 무대 지문을 추가했다. 기존 대사·순서·번역 인덱스·선택지·진행 플래그를 유지한다. 지정된 장면만 상하 프레임과 기억 빛 입자를 표시한다.
- 플레이 설정에서 대화 효과음을 끄거나 대화·UI 움직임을 줄일 수 있다. 움직임 줄이기는 대화 흔들림·맥동·입자와 버튼 크기 변화를 억제한다.

대상 전환: 달빛의 미망인, 재의 왕, 무한서고의 용, 밤의 야수, 마지막 인형사, 고위 검열관 녹스, 셀레네, 막간의 관리자 이후 대화.

## 적용과 검증 범위

기존 씬의 컨트롤러와 런타임 스타일 경로로 적용하며 새 프리팹 생성기도 같은 공통 스타일을 사용한다.
`Prototype/ui-style-preview.html`은 설정 디자인을 살펴보는 별도 HTML 목업이며 Unity 실행 화면이나 게임 설정 저장을 대신하지 않는다.

이번 환경에는 Unity가 없어 컴파일·Play Mode·실제 해상도별 화면·오디오 청취 검증을 수행하지 못했다.
정적 검증에서는 변경/추가 C# 21개 파일의 구문, 병합 표시 부재, 스크립트 GUID, 번역 JSON/키 중복을 확인했다.
대사 카탈로그는 원본과 비교해 8개 장면의 새 메타데이터 외에 대사·순서·선택지·플래그가 동일함을 확인했다.
HTML 미리보기의 JavaScript 구문 검사를 통과했다. 브라우저 렌더링은 실행 환경의 소켓 제한으로 확인하지 못했다.
Unity 확인 시에는 별도 검증 복사본에서 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`를 사용하고 `-quit`를 붙이지 않는다.
확인할 핵심은 설정 변경/재진입, 드롭다운 취소, 패드 포커스와 스크롤, 대사 즉시 완성/선택지/취소, 음악 복귀,
피해 후 회복/교체 시 HP 잔상 초기화, 움직임 줄이기 설정이다. Player 빌드는 이번 요청에 포함되지 않는다.
