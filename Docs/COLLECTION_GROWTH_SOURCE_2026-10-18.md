# 각본집 수집 및 성장 안내 보완

## 변경

- 각본집의 조우·기록 수를 현재 데이터베이스의 유효한 고유 그림자 ID 기준으로 집계한다. 빈 데이터나 중복 종이 전체 수와 진행도를 부풀리지 않도록 한다.
- 목록 갱신 시 선택한 종과 목록 스크롤을 유지하며, 선택 행에 표시를 추가한다. 필터를 바꾸면 목록은 맨 위로 이동하되 선택 종이 포함돼 있으면 유지한다.
- 언어, 파티, 퀘스트, 기억 단계가 바뀌면 프레임당 한 번으로 모아 갱신한다. 저장 객체가 교체되면 이전 각본집을 닫고 선택 개체를 비운다.
- 이미 생성된 설명 스크롤을 재사용하고, 스크롤이 없는 프리팹에만 기존 설명 영역 안에 세로 스크롤을 런타임 구성한다. 현재 보유 개체의 기본 공격·배운 기술과 다음 해금 레벨의 기술을 함께 표시한다. 향후 기억 형태의 기술은 미리 배운 기술로 표시하지 않는다.
- 미조우·빈 목록은 초상 이미지를 숨기고 이전 상세 표시를 정리한다. 새로운 그림자를 선택하면 설명은 맨 위에서 시작한다.
- 기억 복원, 각성, 개인 기억 여정 시작은 현재 저장의 파티나 서고에 실제 포함된 개체만 변경한다. 이전 저장의 같은 ID를 가진 객체나 외부 생성 개체로 성장 처리를 실행하지 않는다.
- 각본집의 성장 행동은 열린 필드 화면에서만 프레임당 한 번 실행한다. 성공·실패 결과를 표시하기 전에 목록의 기억 단계와 초상도 갱신한다.
- 복원 형태의 개인 기억 조건 플래그가 null인 경우 기억 여정 조회에서 예외가 나지 않도록 한다.
- 새 UI 안내는 한글/영문 문구를 제공한다. 기존 프리팹·생성 파일을 수정하거나 재생성하지 않는다.

## 확인 범위

- 별도 검증 복사본에서 Unity 2022.3.62f3 컴파일 및 `ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`로 Editor Play Mode 기동 확인.
- PrologueTheater에서 Player/Grid/GameFlow 초기화 성공, 12초 관찰 중 런타임 오류 0, Unity 종료 코드 0.
- 신규 문구의 JSON·키 중복·서식 인자, 검증 소스 일치 여부 및 기존 수정 파일 해시 확인.
- 기존 컴파일 경고는 남아 있다. 각본집 스크롤·필터 조작, 기술 표시와 실제 기억 복원·각성의 플레이 검증은 이번 기동 확인에 포함하지 않았다. 같은 종을 여러 개 보유하면 기존처럼 가장 높은 기억 단계, 같은 단계에서는 최고 레벨 개체를 표시한다.
- APK/AAB 생성, 에뮬레이터 설치 및 전체 회귀 검사는 실행하지 않는다. 기존 패키지/에디터 버전 수정과 미추적 생성 파일은 보존한다.
