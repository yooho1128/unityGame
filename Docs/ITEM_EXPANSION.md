# 막간 도구 확장

기존 13종의 ID와 효과 enum 0~6을 유지하며 신규 8종으로 총 21종이다.
추가 기준은 Assets/Resources/Data/ItemExpansionCatalog.json이며, 기존 지역 그림자 ID 생성 뒤에 합친다.

| 도구 | 효과 | 구매 금화 | 판매 시작 |
|---|---|---:|---|
| 막간 비스킷 | HP 25 회복 | 18 | 1막 |
| 갈대 이슬병 | 최대 HP 35% 회복 | 45 | 2막 |
| 불꽃 사탕 | FP 1 회복 | 45 | 1막 |
| 연습용 옅은 잉크 | 이번 전투 기록 확률 ×1.35 | 80 | 1막 |
| 새벽 정화차 | 최대 HP 35% 회복 + 모든 상태 이상 정화 | 125 | 3막 |
| 커튼콜 영약 | 최대 HP 65% 회복 + 모든 상태 이상 정화 | 300 | 6막 |
| 주석 달린 기억 대본 | 경험치 900 | 240 | 3막 |
| 완성된 기억 대본 | 경험치 2400 | 640 | 6막 |

판매 금액은 구매 금액의 절반(내림)이다. 마을 공통 판매품으로 등록하되 해당 마을의 막 조건을 적용한다.
기존 전문 품목의 복구 조건이나 해금 순서는 바꾸지 않는다.
불등 여우와 헝겊 무대강아지는 비스킷, 물종 수달은 이슬병, 꿈구슬 토끼는 옅은 잉크를 18% 확률로 1개 떨어뜨린다.
초반 소모품 가격과 대본의 경험치당 가격은 기존 소모품을 기준으로 잡았다. 실제 플레이 경제 균형 검수는 필요하다.

## 사용 조건

- 비스킷/이슬병: 전투와 필드에서 선택한 그림자 회복. 필드에서는 기존 동행·시간대 보정과 초과 회복 미리보기를 따른다.
- 사탕/잉크/정화차/영약: 전투 전용. FP 상한, 더 진한 잉크 적용 여부, 기록 가능 전투 조건은 기존 규칙을 따른다.
- 정화차/영약은 RestoreAndCleanse(추가 enum 값 7). HP가 가득해도 상태 이상이 있으면 사용 가능하고, HP와 상태가 정상인 대상에게는 소비하지 않는다. 기절한 그림자를 부활시키지 않는다.
- 대본: 필드 전용. 기존 경험치 미리보기/레벨 상승 처리 사용. 최고 레벨 대상에게는 소비하지 않는다.
- 각 신규 도구는 64×64 픽셀 아이콘 생성 스타일과 색을 별도로 지정한다. 아이콘은 Unity 콘텐츠 생성 시 제작된다.

## 검증

python Tools/check-item-expansion.py: 21개 고유 ID, 8종 판매 연결/가격/아이콘 스타일, 4개 드롭, 효과 enum 호환성과 필드·전투 연결을 검사한다.
ItemExpansionRegression은 Unity 회귀 검사에 연결되어 있으며 만피+화상/약화 정화, HP+빙결 동시 회복, 초과 회복, 기절 부활 방지, 판매 시점/획득 경로를 검사한다.

현재 환경에는 Unity가 없다. Python 검사와 C# 구문 검사는 실행했으며 Unity 회귀 검사·컴파일·Play Mode는 실행하지 않았다.
별도 검증 복사본에서 Unity 2022.3.52f3의 Completion → Generate Full Game and Audit로 아이템/아이콘/드롭 에셋을 재생성하고 SourceOperationBatch.RunForCi로 기동 검증해야 한다.
재생성 전의 기존 ShadowDatabase/생성 보고서에는 신규 도구가 포함되지 않는다.
