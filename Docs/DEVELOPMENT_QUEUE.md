# 개발 이어가기

Unity 2022.3.52f3 기준. 매 작업 후 README 갱신, 적절한 검증, 일반 main push.
Unity/실기기 실행이 불가능하면 정적 검사와 실행 검증을 명확히 구분한다.

## 다음 우선순위

0. 진명 성장 회귀 검사는 구현 완료. Unity에서 `Validate Full Game` 실행 검증은 남아 있다.
1. 현지화 TSV 가져오기 회귀 검사는 구현 완료. Unity에서 `Validate Full Game` 실행 검증은 남아 있다.
2. 현지화 검사 사각지대 보완 완료. Unity 실행 검증은 남아 있다.
3. 한국어 전용 출시 정책 반영 완료. 언어 행 숨김과 한국어 기준 커버리지 검증의 Unity 실행 확인은 남아 있다.
4. QA 리포트 견고성 보강 완료. Unity·실기기에서 revision 2 리포트 생성 검증은 남아 있다.
5. 빌드 설정 검증 및 CI 진입점 보강 완료. Unity·실기기 실행 검증은 남아 있다.

  빈 개체·전멸 상태로 구성된 전투 파티의 시작을 거부함. 입력 규칙 회귀 검사 추가, Unity 실행 검증은 남아 있음.
