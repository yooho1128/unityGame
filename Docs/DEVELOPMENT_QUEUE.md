# 개발 이어가기

Unity 2022.3.52f3 기준. 매 작업 후 README 갱신, 적절한 검증, 일반 main push.
Unity/실기기 실행이 불가능하면 정적 검사와 실행 검증을 명확히 구분한다.

## 출시 후보 확정 순서

1. 집 Windows PC에서 최신 main을 받고 `Completion → Generate Full Game and Audit`을 실행한다.
2. 생성된 `Docs/Generated/FINAL_GAME_COMPLETION.md`의 본편 차단 항목을 0개로 만든다.
3. Android QA APK로 20분 실기기 시나리오를 수행하고 QA JSON을 가져온다.
4. macOS/Xcode 환경에서 iOS QA를 수행하고 QA JSON을 가져온다.
5. 양 플랫폼 판정이 PASS인 커밋을 1.0 출시 후보로 태그한다. 이후 콘텐츠는 DLC 버전에서 진행한다.
6. 출시 자산 파이프라인을 Unity 2022.3.52f3에서 실행하고 생성 보고서·전투 연출을 육안 검수.
7. 수작업 최종 아트는 현재 핵심 배역 중심이므로 상점 스크린샷·보스·스타터 순으로 180종 교체율 향상.
