# 개발 이어가기

Unity 2022.3.52f3 기준. 매 작업 후 README 갱신, 적절한 검증, 일반 main push.
Unity/실기기 실행이 불가능하면 정적 검사와 실행 검증을 명확히 구분한다.

## 다음 우선순위

1. 현지화 TSV 가져오기 회귀 검사 및 서식 문자열 안전성: 중복/빈값/줄바꿈/서식 오류 검사.
2. 현지화 검사 사각지대: L10n.Text와 생성 UI 문구 수집, 카탈로그 손상·누락 시 실패 보장.
3. 실제 카탈로그의 대화·퀘스트·지역·엔딩 영문 누락을 콘텐츠 묶음별 보완.
4. QA 리포트 견고성: 손상 파일 차단, 앱 버전 외 빌드 식별, 프레임 정지·복귀 기록 점검.
5. 빌드 설정 검증 및 CI 진입점 보강: 필수 씬 순서, SDK/아키텍처, 릴리스 차단 검사.

## 현재 완료

- 모바일 QA/Release 빌드 메뉴와 출시 게이트.
- 현지화 커버리지 보고서·누락 TSV 생성.
- 실기기 기록과 측정값 재판정.
- 번역 완료 TSV 가져오기: 전체 파싱 후 반영, 원본 백업, 미번역 행 보존, 중복 키/열/서식 검사.
