# 모바일 플레이 문제 수정 — 2026-10-17

## 수정 내용

- 동행 그림자는 전투 초상을 원래 월드 크기로 표시하던 문제를 수정했다. 필드 프레임을 별도로 연결하고 높이 0.92타일, 폭 1.15타일 이내로 맞춘다. 처음 등장하거나 전투에서 복귀할 때 플레이어 뒤쪽의 빈 칸으로 배치한다.
- 알아보기 어려운 24×32 필드 이미지를 고해상도 원본으로 교체했다. 주인공의 기존 원본 걷기 시트에서 3방향·2프레임을 다시 임포트하고, 완성 초상이 있는 그림자는 해당 아트를 사용한다. 나머지는 새 공유 몬스터 배역을 사용한다. NPC는 안내자·치유사·상인·학자·전령·경비병 배역으로 표시한다. 180종 각각의 전용 아트를 새로 만든 것은 아니다.
- 전투 교체 목록의 `VerticalLayoutGroup`이 항목 폭을 제어하지 않아 폭이 0으로 줄어드는 문제를 수정했다. 파티·도구·상점·퀘스트 등 동일한 구조도 함께 수정했다. 비활성 템플릿의 버튼 바인딩을 `Bind`에서도 보장하고, 이전 항목은 즉시 비활성화한 뒤 정리한다.
- 전체 UI를 가로 1600×900 기준, 높이 기준 배율로 통일했다. 펼친 폴드와 일반 가로형 화면에서 크기가 과하게 달라지는 문제를 줄였다. 화면 안전영역, 상단 메뉴·지역명·퀘스트 간격, 전투 HP/이름 글자 크기를 조정했다. Android 창 크기 변경을 허용해 접힘·펼침 시 화면 크기 변경에 대응한다.
- 각본집은 목록과 본문을 좌우로 배치하고 항목 폭을 확보했다. 긴 본문은 스크롤해서 읽는다. 기록된 그림자의 컬러 아트를 검게 덮던 표시도 수정했다.
- `A`를 `대화 · 조사`로 바꾸고, 바라보는 대상에 따라 `대화` 또는 `조사`를 표시한다. 대상이 없거나 이동·대화 중이면 비활성화한다. 방향키와 상호작용 버튼은 둥근 테두리 패널과 일정한 터치 크기를 사용한다.
- 첫 초원의 권장 조우 범위를 3~6으로 낮췄다. 초반 필드에서 전투 가능한 동료가 한 명이면 적은 최대 Lv.4, 두 명 이상이면 최대 Lv.6으로 제한한다. 희귀 그림자는 전투 가능한 동료를 두 명 확보한 뒤 출현한다. 초반 새 지역 배역의 기본 HP는 18%, 공격력은 24% 낮추고, 조우 사이 안전 걸음을 14~20걸음으로 늘렸다. 던전·보스·후반 지역에는 이 보호 규칙을 적용하지 않는다.
