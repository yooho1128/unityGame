# 게임 내 퀘스트 추적과 목표 안내

퀘스트 기록장·필드 HUD·월드맵이 같은 미완료 목표를 안내한다.
메인 퀘스트 외에 개인 기억 여정과 소문 퀘스트도 선택해 추적할 수 있다.

## 플레이 방법

1. 기억의 여정(퀘스트 기록장)을 열고 진행 중인 여정을 선택한다.
2. **추적 고정**을 누르면 해당 여정이 HUD에 고정되고 저장된다. 현재 HUD 여정은 목록에서 ◆로 표시한다.
3. **기본 추적으로**를 누르면 메인 여정 우선 선택으로 돌아간다. 고정한 여정을 끝내도 기본 추적으로 복귀한다.
4. **목표 지도** 또는 **추적·지도**를 누르면 퀘스트 창을 닫고 해당 목표에 월드맵 초점을 맞춘다.
   아직 장소를 안내할 수 없으면 버튼에 **장소 단서 필요**를 표시한다.

완료 여정이나 시작하지 않은 여정은 고정할 수 없다. 진행도·보상은 추적 여부와 관계없이 기존 규칙대로 집계한다.

## 안내 범위

- 첫 번째 미완료 목표를 HUD에서 표시하며 전체 목표 진행률은 유지한다.
- **대화**: NPC 이름, 지역, 현재 위치 기준 동서남북을 안내한다.
- **보스 처치**: 보스와 조우 지점으로 안내한다.
- **도착**: 지역과 실제 도착 트리거 지점으로 안내한다.
- **야생 승리/기록 누적**: 현재 또는 가장 가까운 알려진 야생 조우 지역으로 안내한다.
- 다른 지역이면 알려진 연결 경로의 다음 지역, 실제 현재 씬 출구의 방향, 남은 구간 수를 표시한다.
- 관문 조건이나 이동 권능이 충족되지 않은 현재 출구는 방향 표식 대신 잠김 안내를 표시한다.
- 발견하지 못한 숨은 장소와 소문만 들은 장소는 이름·좌표를 안내하지 않는다. 기존 탐험 공개 규칙을 따른다.
- NPC·보스가 현재 씬에 있으면 실제 Transform을 사용하고, 그렇지 않으면 제작 시 지정한 타일 중심을 사용한다.
- 월드맵의 ◆·퀘스트 버튼이 Talk/Defeat/누적 목표에도 연결된다. 기존 Reach 한정 처리를 공통화했다.
- 위치 안내는 이동 방향을 알려 준다. 벽을 피하는 칸별 자동 이동이나 자동 전투를 수행하지 않는다.

HUD는 0.5초 간격으로 방향을 갱신하며 이동·퀘스트·언어 변경에 따라 다시 표시한다.
기록장에 런타임 버튼을 추가하므로 기존 생성 프리팹에도 반영된다.

## 데이터와 저장

- `Tools/export-quest-navigation.py`가 PlayablePrologueGenerator의 실제 NPC/보스/도착 트리거 호출을 파싱한다.
  확장 지역은 생성기의 도착 칸을 사용한다. ID 이름만으로 지역을 추측하지 않는다.
- `Assets/Resources/Data/QuestNavigationCatalog.json`: 54개 퀘스트에 필요한 고유 장소 목표 69개(대화 19·보스 22·도착 28).
  모든 `*` 이외 목표에 배치가 없으면 내보내기가 실패한다.
- 추적 선택/첫 미완료 목표 선택은 `QuestTrackingPolicy`, 위치·공개 상태·방향은 `QuestGuidanceService`가 담당한다.
- 맵 표식은 목적지 조회만 사용하고, 표식마다 씬 오브젝트 검색이나 상세 안내를 반복하지 않는다.
- 세이브 v14의 `trackedQuestId`는 저장 슬롯별이다. 구버전은 고정 없이 메인 우선으로 시작한다.
- 존재하지 않거나 완료된 고정 ID는 초기화 과정에서 정리하고 정상 진행 퀘스트로 복귀한다.
- 추적 설정을 저장할 때 현재 위치 등 런타임 상태도 함께 캡처한다.
- 추적 설정 저장이 실패하면 메모리의 기존 선택을 되돌리고 실패를 안내한다.
- 퀘스트 창에서 지도로 넘어갈 때 기존 입력 잠금을 해제한 다음 지도 잠금을 잡는다.

```sh
python Tools/export-quest-navigation.py
python Tools/check-quest-navigation.py
dotnet run --project Tools/QuestChecks/QuestChecks.csproj
```

## 검증 결과

- 실제 퀘스트/지역/경로/추적/안내 C# 파일을 .NET에서 실행한 **262개 검사 통과**.
  54개 실제 퀘스트의 첫 목표와 69개 배치 참조, 부가 여정 고정, 완료 복귀, 잘못된 핀,
  다른 슬롯 진행도, 실제 NPC 위치 우선, 출구 방향, 잠긴 출구, 숨은 장소 비공개를 확인했다.
  Unity 씬/리소스/저장 브리지는 관리 코드로 대체하며 Unity 네이티브 API·실제 저장 파일 I/O는 실행하지 않는다.
- 배치 내보내기 동일 결과, 저장 실패 롤백/입력 잠금 인계/HUD·지도 연결의 정적 검사 통과.
- Assets/Scripts 런타임 Roslyn 소스 컴파일: 오류 0. 공개 UnityEngine 2021.3.33/uGUI 2018.3.5.1 참조,
  검사 폴더의 Light2D 호환 표면과 구형 uGUI selectedColor 제외를 사용했다. Unity 2022.3 컴파일을 대신하지 않는다.
- 기존 성장 상한 26개·공연 정책 48개, 자동 전투 제거/북쪽 출구/회복/난이도 검사 통과.
- `QuestNavigationRegression`을 Unity 전체 감사에 연결했다. 실제 리소스 커버리지, 추적 우선순위,
  JsonUtility 추적 필드 직렬화, v13→v14 기본값을 검사한다(이 환경에서 미실행).

Unity 2022.3.52f3 에디터가 없어 임포트·에디터 컴파일·Play Mode·실제 모바일 UI 확인은 미완료다.
별도 검증 복사본에서 `Completion → Generate Full Game and Audit`과
`ShadowTheater.EditorTools.SourceOperationBatch.RunForCi`(`-quit` 제외)를 실행한 뒤 다음을 확인한다.

- 개인 기억 여정 고정→씬 이동/앱 재시작→동일 추적 유지, 다른 저장 슬롯 분리
- NPC 대화/보스 처치 후 다음 목표 전환과 완료 후 메인 우선 복귀
- 기록장↔지도 전환/취소 후 입력 잠금 잔여 없음, 모바일 상세 텍스트·버튼 가독성
- 북쪽·동쪽 출구 방향과 실제 NPC 위치, 숨은 장소/잠긴 관문에서 정보 노출·이동 우회 없음

APK/AAB 빌드는 실행하지 않았다.
